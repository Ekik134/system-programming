# ЛР 2. Программа в отладчике

Система: `Windows` · отладчик: `Visual Studio`.

## Остановка и переменные
Программа без отладчика напечатала: `agent: total=6 area=12`.
Точка останова на строке `15`.
До строки 15: p.x = `2001227932`, p.y = `1983542414`, total = `11597868`.
После строки 15: p.x = `3`, p.y = `4`.
Строку 16 отладчик пропустил, потому что `name[8] - объявление пустого массива, команд тут нет`.
name[0] = `97` (код буквы), завершающий ноль в ячейке `[7]`.

## Цикл и функция
На кадре цикла: i = `2`, total = `1`; после следующего шага total = `3`.
В стеке внутри area строк: `2`, сверху функция `debu.exe!area(point p)`.
Команда умножения в машинном коде: `imul`.
Перед printf: a = `12`, total = `6`.
Код завершения программы: `The program '[7488] debug.exe' has exited with code 0 (0x0).`.
